## 📌 5W1H Rule

Every report **must** answer:

* [ ] **Who?** → User/IP/File/Domain
* [ ] **What?** → What happened?
* [ ] **When?** → Timestamp
* [ ] **Where?** → Source (Log/File/Network)
* [ ] **Why?** → Evidence that triggered detection
* [ ] **How?** → Detection rule used by SHADOW
